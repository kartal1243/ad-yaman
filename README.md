# Seyir Terası Fast Food — seyirterasifastfood.com.tr

Alaplı Çekirdek Tepesi / Zonguldak. Çiğ köfte + fast food tanıtım sitesi.
Logo renkleri: lacivert #12225e, kırmızı #e11d2e, sarı #ffb700.

## Dosyalar
- `index.html` → tüm site (menü, hakkında, video, galeri, iletişim)
- `styles.css` → tema
- `script.js` → **MENU dizisini düzenleyerek fiyat güncelle**
- `assets/logo.png` → **Attığın logoyu bu isimle buraya koy** (şu an boş, koyunca sitede görünür)

## Yapılacaklar (sende)
1. `assets/logo.png` dosyasını ekle (mesajdaki logo).
2. Dükkan fotoğraflarını `assets/galeri/` klasörüne at → `index.html` galeri kısmına ekleyeceğim.
3. Tanıtım videosu zaten gömülü: `https://www.instagram.com/p/DZmyKglqiZ0/` (ID değişirse iframe src'yi değiştir).

## GitHub'a atma
1. GitHub'da `seyirterasi-fastfood` reposu aç.
2. Bu klasörün içinde:
```
git init
git add .
git commit -m "Seyir Terasi sitesi ilk surum"
git branch -M main
git remote add origin https://github.com/KULLANICIADIN/seyirterasi-fastfood.git
git push -u origin main
```
3. Repo → Settings → Pages → Deploy from branch → main → site yayında.
4. Domain (seyirterasifastfood.com.tr) panelinden CNAME/A kaydı ile GitHub Pages'e bağla.
